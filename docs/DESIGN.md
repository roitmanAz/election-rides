# כללי עיצוב: מטה רכב

הכיוון (נבחר 2026-11-23): "ירוק", בהשראת אפליקציית הנסיעות Wavespace מ-Dribbble (`inspiration/c1.jpg`).
- רקע אפור-ירקרק בהיר, וכרטיסים לבנים מעוגלים שצפים בצל רך.
- כפתורים גדולים ועגולים, וירוק אחד לפעולה.
- בהיר בלבד, בלי מצב כהה.
- כל הסגנון יושב בקובץ אחד: `green-theme.css`, שמוטמע בכל אחד מחמשת המסכים.
- קודם בונים את הצורה של המסך, ואחר כך מחילים עליו את הקובץ.

## צבעים (tokens)
| שם | ערך | שימוש |
|---|---|---|
| `bg` | `#f2f5f3` | רקע המסך |
| `surface` | `#ffffff` | כרטיסים ופאנלים |
| `ink` | `#121a14` | טקסט, לוחיות קלפי, כפתור סינון שנבחר |
| `muted` | `#4b5650` | טקסט משני |
| `line` / `line2` | `#dce3de` / `#b9c4bc` | קווים / מסגרות שדות |
| `soft` / `soft2` | `#e9eeea` / `#d9e1db` | כפתור משני, תגית, שדה חיפוש |
| `action` / `action-soft` | `#16a34a` / `#e8f7ee` | כפתור פעולה, קו מסלול, שורה נבחרת |
| `ok` / `ok-soft` | `#1f7a3a` / `#e4f3e8` | המתנה עד 15 דקות, נהג פנוי |
| `warn` / `warn-soft` | `#a15f00` / `#fdf0d8` | המתנה 15 עד 30 דקות |
| `bad` / `bad-soft` | `#c92a2a` / `#fde8e8` | המתנה מעל 30 דקות, ביטול, שגיאה |

**הפרדה בין שני הירוקים:**
- **ירוק פעולה** (`action`) הוא תמיד מילוי מלא עם טקסט לבן: כפתור, או קו המסלול.
- **ירוק המתנה** (`ok`) הוא תמיד טקסט כהה על רקע בהיר, ותמיד מלווה מספר.

## גופן
- **Rubik** לכל הטקסט, במשקלים 400, 500, 600 ו-700.
- כותרות ומספרים: 600.
- טקסט רגיל: 400 עד 500.

## צורות
- **כרטיס או פאנל**: לבן, פינות 20px, בלי מסגרת. צל: `0 8px 30px rgba(15,30,20,.08)`.
- **מסגרת המסך**: פינות 24px.
- **חלון קופץ**: פינות 24px עם צל חזק. באפליקציית הנהג החלון עולה מלמטה, כגיליון.
- **פס עליון**: לבן, עם קו דק בתחתית.
- **חיפוש**: שדה עגול לגמרי על רקע `soft`.
- **כפתורים**:
  - ראשי: ירוק, 48px, פינות 14px.
  - משני: `soft` בלי מסגרת.
  - סינון ולשוניות: עגולים לגמרי. מה שנבחר מקבל רקע `ink`.
  - X: עיגול `soft` בגודל 42px.
- **לוחית קלפי**: ריבוע כהה, פינות 8px, ספרות לבנות.
- **תגיות**: עגולות לגמרי.
- **קו מסלול**: ירוק רציף, עם עיגולי תחנה.

## כללי שימוש
- ירוק פעולה רק למה שדורש פעולה עכשיו.
- סולם ההמתנה (ירוק, כתום, אדום) לא משמש לשום דבר אחר.
- כל צבע מלווה גם במספר או במילה, ולא רק בצבע.
- **אין גלילה לצד בשום מסך.** המסכים נמתחים לרוחב החלון, וטבלאות ברוחב קבוע עם קיצור טקסט. במסך צר העמודות נערמות.
- **בלי תג אחרי מספרים** (לא 38′).
- תוכן לא דורס תוכן.
- **גודל כפתורים**:
  - לפחות 38px גובה, וכפתור ראשי 48px.
  - כפתורים משניים לנהג ("ערוך", "סיים לעבוד") קטנים (32px) ובמקום קבוע.
- **כיסא גלגלים**: אייקון SVG, לא מילים.
- **חלונות קופצים**: נסגרים ב-X, בלחיצה מחוץ לחלון וב-Esc.
- **אפליקציית הנהג**: כפתורים ראשיים 56px לפחות, טקסט 17px ומעלה, ופעולה אחת בולטת בכל מצב.
- **מימין לשמאל**: כל דף מוגדר RTL. כשמעתיקים עיצוב מתמונה באנגלית, מהפכים את כל הסידור.
